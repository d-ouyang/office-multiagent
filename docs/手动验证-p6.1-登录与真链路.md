## Case 1 登录页（浏览器，核心）

1. 打开 `http://localhost:8080` → 应看到登录页（没有 token 时不能直接进工作台）。
2. 故意输错：`dev` / `wrong` → 应提示「用户名或密码错误」。
3. 正确登录：`dev` / `Office@2026` → 进入工作台（顶部有任务输入框、退出登录、状态徽章）。

## Case 2 真任务 · 知识库问答（真 LLM + 真检索）

输入框输入：`帮我查一下公司的年假制度` → 点「发送任务」。

**期望**：
- 顶部出现徽章 **「当前回答：知识库问答 Agent」**；
- 时间线里出现 `rag_retrieve` 工具调用（可能多轮）；
- 正文给出年假天数/司龄递增/上限，并**注明依据文件**；
- 完成后状态徽章变 `done`。

## Case 3 真任务 · 能力缺失如实告知

输入：`帮我把这张老照片修复一下` → 发送。

**期望**：徽章「图像修复 Agent」；正文**如实告知**该能力暂未接入，并给替代建议——**不假装已处理**。

## Case 4 真任务 · 文档读取

输入：`读一下 handbook-demo.md，总结差旅报销要点` → 发送。

**期望**：徽章「通用办公 Agent」；出现 `read_document` 工具调用；正文总结交通费/住宿/报销流程（内容来自 `backend/data/upload/handbook-demo.md`）。

## Case 5 登录态边界

- 退出登录 → 回登录页；浏览器直接访问 `http://localhost:8080` 仍先到登录页。
- （可选命令行）未带 token 调任务接口应 401：
  ```bash
  curl -i -X POST http://localhost:3001/api/v1/tasks \
    -H 'Content-Type: application/json' -d '{"text":"hi"}'   # → HTTP 401
  ```

## Case 6 （可选命令行）API 全链路

```bash
# 登录拿 token
TOKEN=$(curl -s -X POST http://localhost:3001/api/v1/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"dev","password":"Office@2026"}' | python3 -c "import sys,json;print(json.load(sys.stdin)['access_token'])")

# 身份回显（应返回 {"employee_id":"EMP001",...}）
curl -s http://localhost:3001/api/v1/auth/me -H "Authorization: Bearer $TOKEN"

# 真任务（NDJSON 流）
curl -N -X POST http://localhost:3001/api/v1/tasks \
  -H 'Content-Type: application/json' -H "Authorization: Bearer $TOKEN" \
  -d '{"text":"帮我查一下公司的年假制度"}'
```

## 常见问题

| 症状 | 原因 | 处理 |
|---|---|---|
| 登录 503 USER_SOURCE_UNAVAILABLE | 网关连不上 MySQL | `docker compose ps` 看 mysql；确认 GATEWAY_MYSQL_* |
| 任务回答"未能查到…工具…404/故障" | 宿主 RAG FastAPI 没在 8000 跑 | 启动 RAG 后端再试（此回答本身是**正确行为**：工具故障如实说） |
| 登录后所有请求 401 回登录页 | 网关重启换了随机 JWT secret | `.env` 固定 `GATEWAY_JWT_SECRET`（已配置 dev 值） |
| 回答明显是模板句"[xx] 处理完成" | backend 没拿到 DEEPSEEK_API_KEY | 确认根 `.env` 有 key 且 `docker compose up -d backend` 重建过 |
