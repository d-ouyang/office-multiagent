# 管理端角色

对照知识库：那边 `role` 和 `kb_role` 是两套，读知识库和管知识库分开。办公这边目前只有一套 `user.role`。

| 角色 | 现在能做 | 以后 |
| --- | --- | --- |
| admin / superadmin | 概览、任务、溯源、充值、代续跑、审计、模型池、系统状态 | 保持运营权限 |
| 未来的 ops | 尚未开通登录 | 只读溯源和用量，不能充值、不能代续跑、不能改模型池 |
| user / staff | 不能进管理端 | 不变 |

代码入口仍是 `_require_admin`：角色不是 admin 或 superadmin 就 403。ops 只预留在本文，不另做登录。

知识库检索的 HTTP 身份仍是服务号 `office-service`，因为办公用户不一定在知识库用户表里。工具返回会带上办公用户名，两边不一致时溯源详情标红。
