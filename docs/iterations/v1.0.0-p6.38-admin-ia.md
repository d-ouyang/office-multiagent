# v1.0.0-p6.38 — 管理端概览与运行溯源（2026-10-25）

## 目标

按 `issues/2026-10-25-execution-checklists.md` 第二节，把管理端从「打开就是用户表」改成先看到今天要处理的事，并能顺着一条运行看到工具和身份。知识库治理和站点内容不动。

## 交付

- 默认页是概览。侧栏分核心 / 次要 / 高级。操作者名字和角色在侧栏上方。
- 概览给出暂停数、按原因拆开的暂停、近 7 日失败、完成率、最近 trace 里的数字未对齐次数、平均工具步数，以及服务健康点。
- 用量页在有暂停时可以跳到暂停任务。配额暂停可以去充值，并带上 user_id。
- `GET /admin/runs` 与详情。任务表有工具摘要。可筛曾检索知识库、数字未对齐、无产物。
- 知识库 HTTP 身份仍是 `office-service`。工具结果带办公用户名，不一致时详情标红。角色表写在 `docs/管理端-角色.md`，ops 只预留、不开登录。
- 登录错误提示改为密码下方的浅红色一句。表单补上 name，登录成功调用浏览器的密码保存。

## 不做

- 不把知识库调用的 `X-Username` 改成每个办公用户。用户不在知识库用户表里时，检索会直接 401。
- 不把结果校验改成硬拦截。
- 不改 rag-qa-system 和 nianan-site。

## 验证

- `tests/test_admin.py` 新增溯源用例：工具序列、身份不一致、数字未对齐次数。管理端与知识库工具测试 21 项通过。
- 前端 `tsc` 通过。
