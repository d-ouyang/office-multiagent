# v1.0.0-p6.37 — 图片上传先 OCR 再交给对话模型（2026-10-25）

## 目标

输入框要能带图片。所有对话模型都当纯文本用：先识别成文字，再交给当前选中的模型。

## 交付

- 文件选择接受 png、jpg、jpeg、webp。上传上限对图片是 4MB，和识别接口一致。
- 识别模型是注册表里的 `deepseek-ocr`，实际调用硅基流动的 `deepseek-ai/DeepSeek-OCR`。它不出现在对话列表。
- 识别文字写进本轮提示，并写明模型看不到画面。识别失败也把原因写进去，不编造图里的字。
- 非图片附件仍走原来的 read_document。

## 不做

- 不把像素发给有视觉标记的模型。
- 不把图片写进长期记忆。

## 验证

- 附件前缀测试：只有图片时提示含识别文字和「看不到画面」，不含 read_document。32 项相关测试通过。
