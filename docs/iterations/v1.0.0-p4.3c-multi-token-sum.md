# v1.0.0-p4.3c — multi 路由 token 汇总 + 层内并行度配置化

**类型**：Phase 4 补齐（p4.3 第三刀）｜ **日期**：2026-10-23
**计划依据**：`docs/PLAN-p4.3-DAG结果传递与层内并行.md` 任务 5+6

## 背景

实读代码发现 multi 路由的 token 账是破的：`multi_node` 只返回 `result`，不返回 `tokens_used` → `run_task` 里 settle 的 `actual=0` → 预扣全额退回。多 Agent 任务的真实 LLM 消耗不计入账本（§十四 对账恒等式在这条路上失效）。

## 交付内容

- **`orchestration/react.py`**：`AgentResult` 新增 `tokens_used: int = 0` 字段（本 ReAct 的真实用量；StubBrain 为 0）。
- **`orchestration/graph.py`**：
  - `spec_agent_runner._run` 跑完把 `brain.usage.total_tokens` 写进 `res.tokens_used`（与 single_node 同模式）。
  - `multi_node` 汇总各子任务用量返回 `tokens_used`；`run_dag` 调用传 `max_concurrency=settings.dag_max_concurrency`（并行度配置化）。
- **`core/config.py`**：新增 `dag_max_concurrency: int = 3`（防 LLM 渠道限流；1=串行回落基线）。
- **`docker-compose.yml` / `.env.example`**：注入 `DAG_MAX_CONCURRENCY`（默认 3）。

- ✅ **真 LLM 冒烟**：multi 路由（3 子任务）`tokens_used=15577`——修复前恒为 0；done 事件携带该值，前端/账本可见。
