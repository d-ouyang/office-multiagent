# v1.0.0-p6.36 — 余额不足横幅不再用旧余额、不再提供继续（2026-10-25）

## 目标

充值到 1,000,000 之后，对话底部仍写着「余额 0，需要 2000」，并给出「继续」。数字是暂停那一刻写进任务里的，不是现在的钱包。继续也不是接着算，而是把原问题整段重跑。

## 交付

- 横幅比较当前钱包和这次预扣。余额已经够，就不显示。
- 仍不够时，文案里的余额来自当前钱包，按钮只留「知道了」。
- 主动暂停和中途出错的横幅仍可重跑。那条路径同样是整段重跑，不是断点续算。
- 删掉系统设置里「目前没有别的个人开关」那句。

## 不做

- 不把 LangGraph 的内存断点接到「继续」上。进程一停，那份存档就没了。
- 不在这一版做图片上传和视觉模型分流。

## 验证

- `quotaPauseText(2000, 1000000)` 为空；余额 0 时文案含当前余额且不含「继续」。derive 测试 20 项通过。
