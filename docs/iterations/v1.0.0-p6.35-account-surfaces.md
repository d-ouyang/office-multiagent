# v1.0.0-p6.35 — 上下文跟随模型，个人中心拆成独立面板（2026-10-25）

## 目标

真机用过一轮之后，对话区和左下角个人中心有九处挤在一起或对不上。这一版把能看的信息对齐到当前模型，把不该塞进小弹层的操作挪出去。

## 交付

- 上下文环的分母用当前选中模型的 `context_window`。官方 V3 仍是登记的 128K；硅基 V3 是 160K；V4-Flash 是 1024K。切换后马上变，已用量仍来自最近一轮。
- 模型列表 DeepSeek 在一起、Qwen 在一起。悬停右侧只展示简介、上下文、渠道和能力，简介已经写在 `models.yaml`。
- 侧栏顶部与对话标题顶对齐。主标题「锅圈 Agent」，副标题「企业级智能办公助手」，下面一行 office-multiagent。
- 管理端从「新会话」下面移到个人中心里的一栏。
- 退出登录用浅红色。个人信息右侧是灰色图标，悬停变浅红；底部文字行不再带重复图标。两者都要二次确认。
- 用量明细是大弹窗，可按模型、日期、用量筛选。每一行带会话 id 和任务 id，点击打开该会话并滚到那次提问。
- 系统设置分成全员和个人。全员只有两项：单任务 token 上限（默认 50000，0 为关闭）和结果数字校验。管理员修改后下一次任务生效。个人侧没有新开关，模型和力度仍在输入条。
- 长期记忆大弹窗：四段背景（工作背景、个人背景、当前关注、近期记录，每段最多 2000 字）加上原来的短条目。背景不占 100 条上限。助手每轮先看到背景，再看到短条目。
- 修改密码单独弹窗。

## 不做

- 不把连接池、密钥、超时做成开关。
- 不把官方 DeepSeek V3 的上下文从 128K 改成 160K。160K 是硅基渠道的登记值。
- 不自动把 WorkBuddy 里的记忆文本导进来。

## 验证

- 前端相关单测 29 通过，`tsc` 通过。记忆与系统设置后端测试通过，迁移 `0012_runtime_and_memory_profile` 已在本地库执行到 head。
- 浏览器：选中 V4-Flash 时右上角为 `0 / 1024K`；切回官方 V3 为 `3.5K / 128K`。模型菜单 DeepSeek 排在 Qwen 前面，悬停能看到简介。系统设置显示上限 50000，管理员可改。用量列表能看到「再出一份安庆的」，点击后打开「看看北京今年卖得怎么样」这场会话并滚到该提问。
