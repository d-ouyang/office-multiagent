# 迭代总结 · v1.0.0-p6.8 — 模型列表重构 + 模型信息展示

> 用户三问（默认模型是哪个/模型详情能不能拿到/模型列表按新清单调整）。Tag：`v1.0.0-p6.8`。

## 1. 默认模型（用户问题 1 的答案）
`settings.llm_brain_model = "deepseek-chat"`——**DeepSeek 官方渠道的 V3**
（api.deepseek.com，走 DEEPSEEK_API_KEY 余额）。前端下拉的"默认模型（DeepSeek V3 · 官方）"
即它；未显式选择时 Brain/会话都用它。改默认改 `config.py` 的 `llm_brain_model` 即可。

## 2. 模型信息（用户问题 2）
注册表本来就带 `context_window / max_output / supports_reasoning / multimodal_input /
cost_per_1k`，本轮补 `description` 字段（每个模型一段人话描述）并随 /models 返回；
前端下拉 option 显示 `名称（上下文 · 思考/视觉）`，选中后输入条上方显示**模型信息条**
（模型 id + 上下文 + 描述）。
