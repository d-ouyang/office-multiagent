# v2.0.0-p3.1 / p4.1 · 标题渐隐蒙层 + 对话区 1200px 居中

## 1. 目标

两个半天级前端小包：侧边栏长标题右缘渐隐（能看见被截断文字的边缘）；主区消息、标题、输入条共用 1200px 内容列，窄屏整屏铺满。

## 2. 交付

- `SessionTitle` 溢出且未跑马灯时加 `is-overflow`；`shouldFadeSessionTitle` 纯函数可测。滚动期间移除蒙层，避免吃掉滚动文字。
- `.session-title.is-overflow`：右缘 26px `mask-image` 渐隐（alpha 蒙层，深浅主题无关）。
- `WorkspacePage` 新增统一内容列 `.chat-column { width: min(1200px, 100%) }`：
  - `chat-header-content`（标题 + 当前 Agent + 上下文环）；
  - `message-list`（消息流 + 欢迎示例，`min-height:100%` 保留 welcome 垂直居中）;
  - `composer-inner`（主 PromptBar + 隐藏文件输入）。
- 拖拽上传、暂停横幅等交互不变；`chat-header` 边框仍全宽，只有内容对齐列。

## 3. 方案取舍与否掉项

- **不用 JS 测量列宽**：`min()` 表达式天然覆盖「≥1200 居中留白、<1200 铺满」，无断点漂移。
- **不在蒙层上做 hover 展开**：悬停已有跑马灯，叠加展开会互相打架。
- **不动 PromptBar 组件**：列宽在外层作用域解决，bits 组件保持独立可用。
- 图表/文件卡片等全宽子件由列容器约束 `max-width`，不改组件内部。
