# v2.0.0-p2.5 · 管理端尺寸对齐 rag admin-console

## 1. 目标

office `/admin` 此前多轮"调大"后间距/字号/控件全面偏大，视觉密度远超 rag 管理端。本步把整套尺寸基准**对齐 rag admin-console**（正文 14px / 控件高 ~34 / 表格单元格 10×12）。

## 2. 交付（全部为前端样式，无逻辑改动）

| 维度 | 旧 | 新（=rag 基准） |
| --- | --- | --- |
| 正文/主题字号 | 17 | **14** |
| 控件高度（Input/Select/DatePicker） | 48 | **34** |
| 表格字号 / 单元格 padding | 18 / 22×16 | **14 / 10×12**（表头 13px 弱色） |
