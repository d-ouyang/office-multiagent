# v1.0.0-p6.39 — 输入条单击 + 模型上限校对 + 管理端改版

## 输入条要点两次
根因：工具栏按钮 `onClick` 里先打开菜单再 `focusInput()`，textarea 的 `onFocus={closeMenus}` 立刻把菜单关掉。第一次点击只剩聚焦，第二次才真正打开。
修法：工具栏主动拉回焦点时跳过这一次 `closeMenus`。

## 单次最多输出
登记在 `backend/config/models.yaml` 的 `max_output`，经 `/models` 显示为「单次最多输出」。这是配置值，不是运行时向厂商拉元数据。
本轮按官方页改了 DeepSeek 官方与硅基 DeepSeek-V3/R1；其余硅基模型沿用原登记。运行时 `TaskTokenBudget` 默认仍是 8192（任务预算，不是厂商上限）。

## 管理端
侧栏只留：概览、任务监控、用户额度、模型池、审计日志。用量与系统状态并进概览。任务监控合并运行溯源，详情用侧栏抽屉画 Q→A 节点流。用户额度精确搜索 + 余额筛选 + 充值弹窗 + 分页流水。模型池按角色看可见模型，并可改名称/描述/参数/渠道/启用。
