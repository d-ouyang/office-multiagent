## 1. 附件引用闭环（p6.8 被挤掉的原承诺）
- **前端**：上传成功不再只出 banner，进输入条上方**附件 chip**（可 × 移除；同名路径去重）；
  **拖拽文件到输入条**即上传（onDragOver/onDrop）；发送时 attachments 随消息，
  本地 user 气泡显示附件名 chip；发送后清空 chip。
- **后端 `/tasks`**：`TaskRequest.attachments: list[str]`（文档目录内相对路径）。
  - `_validate_attachments`（fail-closed）：basename 拍平（`../`/绝对路径/越权引用他人目录全部拒绝）
    → 限定 `data/upload/<username>/` 内 → 必须真实存在，否则 400 BAD_ATTACHMENT。
  - `_compose_task_text`：附件以 **prompt 前缀注入**（不动正文）——
    `[用户随消息上传了附件：a.md、b.pdf。可用 read_document 按文件名读取…]`。
- **落库**：user 消息正文存原文（不混前缀）；附件列表存 user 消息 **trace**
  （`{"attachments":["dev/a.md"]}`，复用现有列，无迁移）——历史重建时前端解析 trace 渲染 chip。

## 2. 会话列表时间 bug（全显示同一时刻）
根因：后端 `list_sessions` 只返回 `created_at` 且按它排序；前端三处把 `updatedAt`
全写成 `Date.now()`（初始加载/流结束刷新）——所有会话都显示"加载那一刻"。
修复：
- 后端：`updated_at = COALESCE(MAX(message.created_at), session.created_at)`，**按 updated_at 倒序**
  （"最后问答"排前面，语义正确）。MySQL/SQLite 均成立，无迁移。
- 前端：三处映射改 `new Date(s.updated_at).getTime()`；本地新建会话才用 Date.now()。

## 3. 相对时间规则（对齐 WorkBuddy）
`formatSessionTime`：1 分钟内 `HH:MM` → 超 1 分钟 `XX分钟前` → `XX小时前` → `XX天前` → 超 7 天 `M月D日`。

## 4. 会话列表折叠/展开
默认最多 **10 条**，超出显示 **`查看更多 (N)`**（N=全部条数），点击展开全部（本会话内保持展开）。
