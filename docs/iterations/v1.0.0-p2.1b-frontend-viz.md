# 迭代总结 · v1.0.0-p2.1b — 前端执行可视化 + NDJSON 流式 hook（Phase 2 收口）

> 对应计划：PLAN-1.0.0.md Phase 2 / v1.0.0-p2.1b。Tag：`v1.0.0-p2.1b`。至此 **Phase 2 全部完成**。

## 1. 目标
把静态前端升级为 **React + Vite + TS** 工程，落地 §15.1 的执行过程可视化：`ToolCallsCollapse` 折叠步骤条 + NDJSON 流式消费 hook，能拉 `/api/v1/demo/stream`（经网关白名单透传）把异构事件渲染成可折叠的执行过程。

## 2. 做了什么
- 前端工程化：`package.json`（React 18 + Vite 5 + TS + vitest + lucide-react）、`vite.config.ts`（dev 代理 `/api`→网关）、`tsconfig(.node).json`、`index.html`、多阶段 `Dockerfile`（node build → nginx 伺服 dist + 反代 `/api`→gateway）。
- `lib/ndjson.ts`：`LineBuffer`（按 `\n` 切行、残行留缓冲）+ `parseEvent`（坏行返回 null 不中断）——§15.2 解析核心，纯函数可测。
- `lib/consume.ts`：`consumeNdjson(res, onEvent)` 读 ReadableStream → TextDecoder → LineBuffer → 逐行回调。
- `lib/derive.ts`：把事件流折叠成 `toolCalls`（按 tool_id 归并 start/observation/end）/ 正文 / 思考 / 产物 / 来源。
- `hooks/useNdjsonStream.ts`：fetch + AbortController（中断）+ 状态机（idle/streaming/done/error）。
- `components/ToolCallsCollapse.tsx`：移植 `weight-loss-agent` 同名组件（去 tdesign，用 lucide + CSS 变量）——running/completed/error 状态、按工具类型映射图标、汇总图标条、最新运行工具置顶、整体折叠/展开、单工具展开看入参/结果。
- `components/EventTimeline.tsx` + `pages/DemoPage.tsx` + `App`/`main`/`styles.css`：完整演示页。

## 3. 否掉的方案（最值钱）
- **去 tdesign 依赖**：参考组件用 tdesign-react + tdesign-icons（重）；改用 **lucide-react +  CSS 变量**等效实现，前端依赖从"重 UI 库"降到 react/lucide 两个，构建产物 160KB(gzip 51KB)。
- **§15.2 的 Worker 卸载（逐行 parse / MD 渲染放 Worker）、双层缓冲、虚拟滚动本轮不接**：先落地可测的 inline 消费（`consumeNdjson`），Worker 复用同一 `LineBuffer`/`parseEvent` 即可接，但「为优化引入未测分支」违背本项目纪律——留作明确后续，文档标注。
- **不在前端放任何密钥/直连后端**：前端只调同源 `/api`，由 nginx→gateway→backend，鉴权在网关。
