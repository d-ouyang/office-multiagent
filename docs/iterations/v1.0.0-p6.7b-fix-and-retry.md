# 迭代总结 · v1.0.0-p6.7b — 答案消失修复 + LLM 网络重试

> 用户两轮测试反馈（开代理 DNS 失败 / 答案要刷新才出现）。Tag：`v1.0.0-p6.7b`。

## 1. 根因 1（前端）：done 后答案瞬间消失
`done` 时本地 `reset()` 清空流式事件，却**没把终答固化进本地消息列表**——正文从界面
瞬间消失，刷新后才从 trace 读回。与用户"最终没出现答案，刷新后出现"完全吻合
（p6.2c 重构 WorkspacePage 时把 p6.2a 的固化逻辑弄丢了）。
**修复**：done 时先把 `{role:'assistant', events 快照}` 固化进 messages 再 reset；
**error（断流）同样固化**——已收到的部分不丢，banner 提示连接中断。

## 2. 根因 2（后端）：LLM 网络失败无重试
第一轮"模型调用失败 ConnectError [Errno -2]"= 宿主代理影响容器 DNS（环境问题），
brain 如实报错的行为正确，但**一次网络抖动就整任务失败**缺乏韧性。
**修复**（`core/llm.py`）：
- `chat`：网络类瞬时错误（DNS/连接/超时/5xx）自动重试 2 次（0.8s/1.6s 退避）；
  4xx 鉴权/参数错误不重试；
- `chat_stream`：**首个内容块到达前**失败同样重试；**已向用户吐过字（正文或思考）
  后失败不重试**——重复输出比失败更糟，如实终止；
- 重试语义经 4 个新单测锁定（重试成功/4xx 不重试/首块前重试/已出字不重试）。

**环境建议**：开 Clash 代理时把 `localhost/127.0.0.1` 加入绕过列表，或临时关代理——
代理会影响 Docker 容器 DNS 与浏览器对 localhost 的流式连接。
