## 交付内容

- **`orchestration/orchestrator.py`**：`run_dag(..., max_concurrency=3)`——同层无依赖子任务用 `ThreadPoolExecutor` 并行（ReAct 是同步函数，线程池是正确姿势；裸 asyncio.gather 包同步函数不会并行）；层间仍串行，依赖顺序不变；`max_concurrency<=1` 或单任务层回落串行基线；结果按 `dag.subtasks` 顺序重建，汇总文本确定（可对账）。
- **`core/events.py`**：`EventSequence` 加 `threading.Lock`——并行子任务并发 `next()` 时，无锁读-改-写会产生重复 seq（前端按 seq 排序会乱）。
- **`orchestration/graph.py`**：multi 子任务脑改 `stream=False`——层内并行时若各子任务逐字推 content_delta，多 Agent 终答会字符级交错成乱码；块状推送下每个子任务的思考/终答是完整事件，并行只加速执行、不破坏可读性。单 Agent 路径（single_node）仍是逐字流，不受影响。
- **`orchestration/brain.py`（真跑冒烟抓到的 bug 修复）**：非流式路径漏了 p6.3 混合策略——模型输出协议 B 的自然语言终答时，非流式路径当成「无法解析为 JSON」直接停掉（流式路径有 `looks_like_json` 判定，两条路径不一致）。现在：以 `{` 开头但非法 → 如实停止；非 JSON → 自然语言终答。**修复前 multi 并行子任务全部哑火，修复后正常产出。**
