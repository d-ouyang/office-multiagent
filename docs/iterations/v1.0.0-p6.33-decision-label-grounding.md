# v1.0.0-p6.33 — 决策小模型标签语义校准（2026-10-24）

p6.32 上线后的真模型冒烟发现：Qwen 对「看看上海卖得怎么样」给出的理由是
「查询上海销售情况」，却把标签选成 `general`。结构化 JSON 合法不等于语义正确。

本版在封闭分类提示中补齐 7 类标签定义、业务数据判定原则和 3 个少样本示例，明确：

- 城市/门店/时间/商品 + 销量、金额、订单、经营表现 → `analysis`，不能是 `general`；
- 公司制度、手册、知识库 → `rag`；
- 制度结果再交给数据分析才是 `multi`；分析后导出/画图/写文档仍是 `single`。

真机重跑「看看上海卖得怎么样」：`analysis / single / data_analysis`，分歧日志如实记录。
