# 迭代总结 · v1.0.0-p6.17 — 按清洗表生成图表

> Tag：`v1.0.0-p6.17`。

## 1. 目标
用清洗后的表画出常见图，预览能看到中文，文件和数据库记录对得上。

## 2. 做了什么
- `render_chart` 用 Matplotlib 出 SVG。支持 bar、barh、line、area、pie、scatter、heatmap、hist。
- 必填 `clean_id`。分类、数值列、汇总方式、过滤和分组都是参数。折线和面积按横轴排序；柱状按汇总值取前若干类。饼图超过 8 类并成「其他」，有负数就拒绝。
- SVG 把文字留成字符（`svg.fonttype=none`），不在服务器上找中文字体。预览用浏览器字体显示。
- 文件写到 `data/upload/<用户名>/_out/g-<编号>.svg`。这条路径挂在宿主机 `./backend/data`，不是系统临时目录，重建镜像不会删。
- `asset` 增加 user_id、name、rel_path。文档和图表生成成功后各写一行。数据库只存路径，不存文件字节。
- 回复下方的「生成文件」对 svg 用图片预览。

## 3. 否掉的方案
- 不把中文字体打进镜像。缺字时 Matplotlib 会把字画成方框；改成浏览器绘制后，服务器字体缺失不再影响预览。
- 不让模型提交一串数据点。图和 `analyze_table` 一样，只读清洗结果。
- 不把 svg 放进系统 `/tmp`。那个目录不在数据卷上，容器一换就没了。

## 4. 验证
- `tests/test_tools_chart.py`：柱状图 SVG 含「上海」和标题；折线、饼图、热力、散点、直方图可生成；饼图拒绝负数；asset 记下 user_id 和 `_out/g-` 路径。
- Agent 白名单与「不编造」提示词测试通过。

## 5. 风险
- 用别的软件打开 SVG 时，如果那台机器没有中文字体，标签会空着。在本系统页面里预览不受影响。
- 数据库迁移 0005 没跑过的环境，落库会失败并删掉刚写的文件，避免只有文件没有记录。
