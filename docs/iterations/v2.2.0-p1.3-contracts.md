## 契约设计要点

- **PolicyDecision**：`allow=False` 时其余字段即「该怎么办」——现状映射已对齐
  （quota 暂停=reason/budget_cap；预算暂停同构），B3 收口后事件构造器由判定驱动。
- **StateSnapshot**：`version` 对齐事件流 seq——**恢复语义的基石**：≤version 的步骤
  不重算（C3 把节点内重跑收窄到精确 step 的依据）；`lease_owner` 预留 C2
  （MySQL GET_LOCK，不碰 Redis 红线）。
- **EvalCase**：三入口回流形态——人工灰度用例（expected 手写）、validator 数字对账
  失败（expected=观察数字）、点踩流水（verdict 直接 fail）；`to_dict` 的 JSON 即
  E1 golden set 的文件格式。
- 分层纪律重用自 RAG password_policy：判定与存取分离，契约层零数据库依赖。
