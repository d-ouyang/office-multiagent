# v1.0.0-p6.40 — 管理端 antd 深色主题与表格/用量/审计打磨

15 个提交，`cursor/admin-antd-polish-d214` 分支。前端 25 个文件 + 后端 4 个文件，约 +2784 / -951。

## 引入 antd

- 新增依赖 `antd@^6.6.7` 与 `@ant-design/icons@^6.3.4`。
- **不是整站替换**：按需引入，收口在 `frontend/src/admin/ui.ts`，只在 `/admin` 使用；聊天工作台沿用原组件，避免打包体积和样式互相串味。
- 深色主题收在 `frontend/src/admin/theme.tsx`，配套样式 `frontend/src/admin/admin.css`。

## 表格与分页

- 分页改成底部分页；筛选改成**即时筛选**（`useDebouncedValue` 防抖），不再需要点查询按钮。
- 列宽按比例分配、只保留一层纵向滚动，长文本统一走 `ellipsis.tsx` 省略。
- 任务表：id 列加宽并固定宽度，只让摘要列弹性；去掉「原因」的幽灵列并重排宽度。
- 任务 id、用户工号支持**点击复制**。各表字号统一。
- 新增通用列表页 `frontend/src/admin/AdminListPage.tsx`。

## 用量概览

- 新增 `UsageChart.tsx`：按模型分色的**竖向柱状图**。
- 圆角只给整根柱子的顶部（中间段不圆角，避免柱身出现断续的圆角拼接）。

## 任务监控与实走路径

- 新增 `FlowPathSvg.tsx`：把任务里的 Q→A 节点流画成 SVG 实走路径。
- 详情抽屉 `TaskDetailDrawer.tsx` 重排；任务表补工具摘要。

## 模型池

- 模型列表**显示模型 id**；编辑从弹窗改成**抽屉**；去掉表格悬停态。
- 支持**新建模型**：后端新增 `POST /admin/models`（`routes.py` 的 `admin_create_model`）。

## 后端配套

- `model_registry.py`：管理端新建的模型**只写 `models.overrides.yaml`**，不动手写的 `models.yaml`；
  `_apply_overrides` 会把 overrides 里 yaml 中不存在的 id 补进登记表；新增模型 id 校验正则
  `^[a-zA-Z0-9][a-zA-Z0-9._-]{0,63}$`；抽出 `_write_overrides()` 并在写完后 `reload_registry()`。
  坏掉的覆盖行跳过，不拖垮整张登记表。
- `run_trace.py`：补全实走路径所需的数据结构。
- `audit_repo.py`：审计查询补字段。
- **部署变更**：`docker-compose.yml` 里 `./backend/config` 的挂载去掉 `:ro`——
  管理端要往该目录写 overrides，只读挂载会导致写入失败。

## 登录与个人中心

- `AdminLoginPage.tsx`、`AdminProfilePanel.tsx`、`AdminApp.tsx` 一并对齐 antd 与深色主题；
  `api.ts` 的错误处理收敛到 `errors.ts`。

## 测试

- 后端：`backend/tests/test_run_trace.py`（新增）、`test_admin.py`、`test_models.py` 调整。
- 前端：`frontend/src/lib/admin.test.ts` 扩充。
