# 迭代总结 · v1.0.0-p6.23 — 会话操作改为点击，删除用弹窗确认

> Tag：`v1.0.0-p6.23`。

## 1. 目标
会话操作不要在悬停时自己弹开。删除要有明确的确认框。

## 2. 做了什么
- 悬停会话时，时间仍换成操作图标。悬停图标只显示「更多操作」。
- 点击图标才展开菜单。置顶、重命名、删除会话都是图标加文字。
- 删除打开确认框：标题带会话名，说明消息会一并删除且无法恢复。取消不删，确认才删。

## 3. 验证
- 未点击时菜单不出现。点删除先出确认框，点取消不会调用删除。点确认才会。

## 4. 下一步
把扫描件和图片读通：文字层为空时用 DeepSeek-OCR 转成文字；选了视觉模型时把图片放进请求。
