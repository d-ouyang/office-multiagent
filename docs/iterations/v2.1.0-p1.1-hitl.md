# v2.1.0-p1.1 — HITL 任务中补充输入 + 查询优化（2026-11-10 上线）

分支 `feature/2.1.0-hitl`，18 commits（P1-1a~r），pytest 488 / vitest 117 全绿。

## 核心：任务中补充输入（HITL）

- **ask_user 工具**：模型可发起补充输入请求（缺失型 + 需求确认型），任务挂起 `paused_input`，checkpoint 落盘（`CHECKPOINTER_BACKEND=sqlite` 必开）。
- **多问题向导**（前端）：一次最多 4 题，n/N 翻页、编号选项（点选即进下一题）、✏️其他补充、跳过此题（如实注入「（跳过）」）；单问题/最后一题选完自动续跑。need_file 题裸选上传未传 → 挂在本题等文件，上传完自动续跑。
- **会话状态三件套**：ask 卡片（✕ 可收起）→「重新打开」恢复条 → 侧栏「待确认●」徽章（list_sessions.has_pending_input）。挂起/二次挂起均落库消息（user 问题 + assistant 中间态 trace）——刷新对话不丢。
- **预算暂停（paused_budget）**：token 上限触达 → interrupt 落档，用户可「继续（重置预算）/ 放弃本轮」。memory 后端回落收尾终答（基线不变）。

## 查询与产物优化

- **query_orders metrics 数组**：一次聚合多指标宽表（m_<指标> 列，≤6）；单值 metric 完全兼容（metric_value 列名保留）。
- **结果缓存**：同参数重复查询直接回缓存（cached=true，TTL 600s / 64 条 / 错误不缓存 / 重启失效）。
- **产物索引（P0 轻档）**：追问任务上下文注入前任务 clean_id 索引（≤5 条，JSON/repr 双解析、最新优先）——报告组装不重画图，口径变化才新查询。
- **交付物展示规则**：图表/流程图=过程产物（ProcessTrace 内实时渲染 + hover 下载 ⬇：png 白底 2x / svg）；消息底部只放文件级 artifact；render_chart svg 加 no_artifact（png 照落盘供报告嵌图）。

## 可观测性

- **缓存命中率**：deepseek prompt_cache_hit_tokens → brain.usage → TaskState → done 事件 → token 弹窗进度条「缓存命中 X%」。
- **挂起消息 meta**：显示「⏸ 任务未完结」，不展示预扣伪值；中间态消息隐藏复制/点赞/点踩。
- **预算文案**：精确到「已消耗 X/Y，剩余额度不足以安全发起下一次调用」。

## 修复（实测踩过）

- 旧格式 paused_input 崩渲染（normalizeAsk 三层防御）；续跑失败不落库成僵尸任务；deriveFailure 把 paused_* 全当余额不足；二次挂起不落库内容消失；双下载按钮；hover 抖动（time/ops 锁 16px）。

## 上线标注

- **生产 `/opt/office/.env` 必须加 `CHECKPOINTER_BACKEND=sqlite`**——HITL/budget 续跑依赖 checkpoint 落盘，memory 后端重启后存档失效（响亮报错不静默重跑）。
