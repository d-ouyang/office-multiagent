# v2.0.0-p2.8 · 反馈图标即时激活修复 + 节流

## 现象与根因

用户报告：点赞/点踩提交成功后 icon 没有立刻变实心。根因是 `ChatMessage` 的同步 effect：

```
useEffect(() => setFeedback(msg.feedback ?? null), [msg.id, msg.feedback]);
```

提交成功后本地 `setFeedback(新态)` 了，但**父级 messages 里的 msg.feedback 还是 null**；下一次父级重渲染（余额刷新、计时器、任何 state 变化）都会执行该 effect 把激活态**打回空心**。

## 修复（三处）

1. **服务端真相回写**（WorkspacePage）：`onFeedbackSubmit/Cancel` 成功后 `setMessages` 更新对应消息的 `feedback` 字段——本地乐观态与服务端真相一致，不再有"旧 props 回流"。
2. **effect 只按消息 id 复位**：`[msg.id, msg.feedback]` → `[msg.id]`；`msg.feedback` 由父级在成功路径上同步，不能做依赖（否则乐观态被冲掉）。
3. **乐观 + 节流**：点击立即乐观变实心（失败回滚 + 就地红字提示）；节流用 **ref**（`fbBusyRef`）而非 state——同一渲染批次内的连点读到的仍是旧闭包值，state guard 会被击穿（测试实锤：act 内三连点调了 3 次接口），ref 同步置位则同批次也拦得住。

## 测试

vitest 106 passed（+4：父级重渲染不回退 / 节流三连点只调 1 次 / 失败回滚与错误提示 / 既有状态机用例全绿）。
