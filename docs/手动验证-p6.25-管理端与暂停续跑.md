## 4. 用户主动暂停 → 继续

**操作**：前端发一个较复杂的任务（如「先清洗 sales_oct.csv，再按城市汇总销售额做分析，最后生成月报」，先上传该 CSV），流式进行中点「停止」。

**预期**：
- 消息里出现 **⏸ 已按你的要求暂停。本轮已产生的调用不退，可稍后点「继续」重跑。**
- 下方出现黄色横幅：`任务已按你的要求暂停，可点「继续」重跑` + 「继续」「暂不」按钮。
- 数据库：`SELECT id,status,pause_reason,retry_of FROM task ORDER BY created_at DESC LIMIT 2;` → 该任务 `status=paused_user, pause_reason=user`。
- 点「继续」→ 重新流式输出（新任务），跑完后 `retry_of=原任务 id`，原任务状态变 `resumed`。
- **刷新页面** → 横幅不重复出现（原任务已 resumed）。

**curl 版**：

```bash
# 后台发起
curl -s --noproxy '*' -N -X POST localhost:3001/api/v1/tasks \
  -H "Authorization: Bearer $(cat /tmp/office_token.txt)" -H 'Content-Type: application/json' \
  -d '{"text":"先清洗 sales_oct.csv，再按城市汇总销售额做分析，最后生成月报","attachments":["sales_oct.csv"]}' \
  -o /tmp/p1.ndjson &
sleep 4
RID=$(head -1 /tmp/p1.ndjson | python3 -c "import sys,json;print(json.loads(sys.stdin.read())['run_id'])")
curl -s --noproxy '*' -X POST "localhost:3001/api/v1/tasks/$RID/pause" \
  -H "Authorization: Bearer $(cat /tmp/office_token.txt)"
# 预期：{"ok":true,"task_id":"<RID>"}
sleep 6
tail -2 /tmp/p1.ndjson
# 预期：done 事件 status=paused_user

curl -s --noproxy '*' "localhost:3001/api/v1/tasks/$RID" \
  -H "Authorization: Bearer $(cat /tmp/office_token.txt)" | python3 -m json.tool | head -12
# 预期：status=paused_user, pause_reason=user, pause_payload={"message":"用户主动暂停"}

curl -s --noproxy '*' -N -X POST "localhost:3001/api/v1/tasks/$RID/resume" \
  -H "Authorization: Bearer $(cat /tmp/office_token.txt)" | tail -2
# 预期：done 事件 status=multi（或 single），带 tokens_used>0
```

## 5. 配额不足暂停 → 充值 → 继续

```bash
# 把 dev 余额压到 100（小于预扣 2000）
docker exec office-multiagent-mysql-1 mysql -uoffice -poffice_pass office \
  -e "UPDATE wallet SET balance=100 WHERE user_id=1;"

curl -s --noproxy '*' -N -X POST localhost:3001/api/v1/tasks \
  -H "Authorization: Bearer $(cat /tmp/office_token.txt)" -H 'Content-Type: application/json' \
  -d '{"text":"查一下公司的年假制度"}' -o /tmp/q1.ndjson
QID=$(head -1 /tmp/q1.ndjson | python3 -c "import sys,json;print(json.loads(sys.stdin.read())['run_id'])")
tail -2 /tmp/q1.ndjson
# 预期：quota_paused 事件 {balance:100, needed:2000}；done status=paused_insufficient_quota

curl -s --noproxy '*' "localhost:3001/api/v1/tasks/$QID" \
  -H "Authorization: Bearer $(cat /tmp/office_token.txt)" | python3 -c "
import sys,json;t=json.load(sys.stdin)['task'];print(t['status'],t['pause_reason'],t['pause_payload'])"
# 预期：paused_insufficient_quota quota {'reason': '余额不足，已暂停', 'balance': 100, 'needed': 2000}

# 充值 → 继续
curl -s --noproxy '*' -X POST localhost:3001/api/v1/admin/users/1/recharge \
  -H "Authorization: Bearer $(cat /tmp/office_token.txt)" -H 'Content-Type: application/json' \
  -d '{"amount":50000,"note":"验证据配额暂停后续跑"}'
curl -s --noproxy '*' -N -X POST "localhost:3001/api/v1/tasks/$QID/resume" \
  -H "Authorization: Bearer $(cat /tmp/office_token.txt)" | tail -1
# 预期：done status=single + tokens_used>0
```

**前端**：横幅会显示 `余额不足已暂停（余额 100，需要 2000）。充值后点「继续」`；在管理页给自己充值后点「继续」即可。

## 7. 已知限制（不判失败）

- 续跑是**重跑式**（不是断点续跑）：多 Agent 任务会重新执行已完成子任务，重复计费。
- 取消/报错按**预扣额结算**（不退）：防"发起即暂停"套退款；任务行 `tokens_used` 同步记该值。
- 暂停信号是**进程内**的：backend 重启后，运行中任务的暂停请求会失效（409 NOT_RUNNING）。
